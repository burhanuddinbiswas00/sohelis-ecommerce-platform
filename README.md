# Soheli's - Traditional Kantha & Modern Fashion Brand

Welcome to the official repository and documentation for **Soheli's**, a modern D2C ethnic fashion brand representing traditional Bangladeshi cottage industry Nakshi Kantha work through contemporary silhouettes.

## Project Structure
- `docs/brand-blueprint.md`: Brand concept, USP, product range, and target audience.
- `docs/operational-workflow.md`: Supply chain, production flow, and fulfillment architecture.
- `docs/content-calendar.md`: 1-month social media launch calendar.
- `docs/frontend-code.md`: React.js source code (Navbar, ProductCard, Home).
